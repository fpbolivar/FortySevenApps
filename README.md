### Set up :
1. Clone the repo and cd into it.
2. In your terminal ```composer install```.
3. Rename or copy ```.env.example``` file to ``.env``.
4. In your terminal ```php artisan migrate```.
5. php artisan key:generate.
6. Set your database credentials in your ```.env``` file.
7. ```php artisan serve``` or use virtual host.
8. Visit ```localhost:8000``` in your browser for admin panel.
8. Visit ```localhost:8000/admin/login``` in your browser for website.
9. Visit /admin if you want to access the admin panel. Admin Email/Password: ```admin@gmail.com```/```123456```.
